# 训练卡片与星期编辑切换修复

日期：2026-11-10。版本：`v2026.11.10-compact-plan-editor`。

## 使用效果

训练项目保留完整动作说明，长文字正常换行。缩小卡片上下留白，说明下方的“记录组数”和右侧完成勾选位于同一水平线；卡片随文字长度自然增高，不再为按钮预留多余空白。

进入“计划 → 训练计划管理 → 展开”，在“编辑星期”中选择任意星期后，星期名称、训练重点和动作列表立即显示所选日内容，无需退出或重启。顶部星期标签和“本周训练顺序”中的“编辑”也会同步更新管理区域。

切换星期会保留当前页面内各日未保存的修改。返回原星期可继续编辑；点击保存只保存当前所选日，其他星期的草稿仍待各自保存。默认范围为“本周所选星期”；选择“所选星期 + 后续周模板”才会同时更新后续周模板。草稿不等于已保存计划，刷新或离开前仍需保存。

原有组数记录方式保持：点击“记录组数”填写该项目完成组数；勾选完成按计划组数记录并同步统计，取消完成同步撤回对应组数。本周训练模块换序、动作库编辑和 JSON 导入方式保留。

## 原因与修复

手机训练卡片原先把“记录组数”放在动作文字内部，而完成按钮属于外层布局，导致两者分处不同位置，撑大卡片。现在把两个控件放在同一个操作行，动作文字单独占据上一行。

iOS 星期切换为了保留顶部切换动画，会直接更新已有面板并提前返回，绕过普通页面重绘。旧逻辑因此没有同步更新计划编辑器，星期选择与实际显示内容脱节。修复后，该快速切换路径也会立即更新基础编辑字段、可视化编辑内容与计划相关视图；更新字段前先保留正在编辑的草稿。
