## 性能改动

- 保留所有原始文件，生成有内容摘要的轻量 WebP 动画和静态 WebP 首帧；浏览器优先显示首帧，图解可见后再下载、播放动画。
- 用户暂停或关闭图解时释放动画 URL；减少动态效果或省流量设置启用时，先显示静态图，手动播放才下载动画。原有静态图明确标记为静态图解。
- WebP 加载失败时回退原 GIF，缓存空间不足时仍展示已成功下载的图片。
- 动图独立缓存，命中时不发起后台重下载。核心版本升级时迁移并保留已下载动图，不清空它们。没有预缓存整个动图库。
- 新 AI 候选位于独立审核目录，未进入生产媒体清单。

56 个本地媒体文件（54 个动画、2 个静态 WebP）的动画/图像有效载荷从 19,838,463 字节降至 8,577,616 字节，减少 56.8%。额外静态首帧共 684,336 字节；若所有媒体和首帧都下载一次，合计约 9.26 MB，仍少于原来的 19.84 MB。动作原图未被覆盖。

逐项检查了原始文件 SHA-256、尺寸、动画总时长和循环次数，错误为零。WebP 时长在读取帧后验证，避免优化后意外加速动画。

## 浏览器测量

使用本地 Chromium，关闭缓存，模拟 80ms 延迟和 200,000 字节/秒下载。样本是已有的保加利亚分腿蹲 GIF：

| 指标 | 原始 GIF | 优化版本 |
| --- | ---: | ---: |
| 动画文件 | 433,228 B | 109,606 B |
| 完整动画载入 | 2,265 ms | 725 ms |
| 静态首帧 | 无单独首帧 | 10,124 B，123 ms |

这是单个样本的一轮受控本地测量，不是生产站点的平均速度或所有设备的保证。原 GIF 的浏览器渐进显示可能早于完整载入，因此没有把完整载入时间误称为原图首次可见时间。

6 项浏览器检查通过：打开动作库不批量下载图像、详情只取自身首帧和动画、暂停释放动画 URL、减少动态效果模式、手动播放、原 GIF 回退。7 项专项测试覆盖清单、审核边界、缓存迁移与命中及缓存配额失败。全量对照见 `exercise-media-regression.json`。
